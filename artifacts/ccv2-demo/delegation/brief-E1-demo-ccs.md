Process contract: a native tool reads ONE JSON packet on stdin `{call, attempt, capability, inputs, output_dir, resources}` and prints ONE JSON object on stdout `{"outcome": "ok"|"partial"|"error", "outputs": {...}, "reason": "..."}`. Handles in inputs are keys into `resources` (e.g. `resources[inputs['workspace']]['path']`). An empty result is not an error. A successful call may report a negative result.
