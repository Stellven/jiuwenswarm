# Ordinary skill descriptions (prose only)

## Calculate
Use the calculator to summarize a column of numbers. Choose count, sum, mean,
minimum or maximum. Supply numbers directly, or use decimal strings when exact
decimal values matter. Review the result while doing the task; report errors
rather than inventing a value.

## Normalize a table
Import a CSV or JSON table with the requested columns. Supply the CSV delimiter
when appropriate. Preserve the data and its order. Review imported rows before
using the normalized table; flag malformed input.

The deterministic skill-route simulation supplies inputs from usage.py and
compares observable results to an independent oracle. It does not execute this
prose with a model, simulate human reasoning, or call JiuwenSwarm. It gives the
skill route perfect immediate recognition of a wrong observable result, a
favorable assumption. An undeclared tool observed on the identical inputs has
identical results under this observation policy; it is not a separate measured
third arm. No defect table or declaration guides its use sampling.
