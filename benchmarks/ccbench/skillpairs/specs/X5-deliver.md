# Outcome X5: write a delivery report that states only what the evidence supports
Given measured results, run logs and a short experiment description, write a delivery report: what was done, what was measured, what the results show, and the limitations. Every number or claim must be supported by the supplied evidence; say plainly what was not measured or cannot be concluded.
Example input (short): measurements baseline 0.50, treatment 1.00 over 48 items, 3 repeats each; log shows all six runs exited 0.
Example output (short): treatment 1.00 vs baseline 0.50 on the same 48 items; repeats are identical so they are not independent samples; no generalization claimed.
