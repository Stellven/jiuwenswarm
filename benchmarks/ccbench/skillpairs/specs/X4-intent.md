# Outcome X4: understand a user's request before work starts
Given a user's request for research work, list the constraints the user actually requires, and list anything ambiguous, missing or contradictory that must be resolved before starting. Do not start the work and do not silently pick one reading of a contradiction.
Example input (short): "Use only the standard library, use numpy for speed, finish in 10 minutes."
Example output (short): required: 10-minute limit; conflict: standard-library-only vs numpy.
