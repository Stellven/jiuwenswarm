# Breadth-first local value cases

`python -m benchmarks.harbor_suite.value_cases inventory` lists 80 distinct
development tasks, four per logical capability. `freeze --output NEW_DIRECTORY`
exports identical public inputs/response schemas for both arms, private literal
expectations separately, and an ordinary native skill/helper. This module has no
provider dispatch and changes no registry or active Library association.

`offline --output NEW_DIRECTORY` runs 16 table/calculation/report tasks through
the actual installed deterministic workers and the standalone ordinary Python
helper. `--typed` selects the additive typed utility implementation when present.
Every response, worker packet, refusal/error, wall time and grade is retained;
each of the other 64 cases remains an explicit `not_run` row. Output directories
must be new. Default repeats are one. No generated observation is bundled as a
claimed campaign result.

These direct measurements compare deterministic capabilities and helper quality.
They do **not** measure native-agent skill use, complete CC units, live gates,
planning improvement, protected evidence custody or semantic-verifier accuracy.
Both runnable sides can be perfect: a competent helper is an intentional control.
Count productive completion separately from expected refusal. A product/schema
or infrastructure error is unavailable, never a successful negative control.

The remaining 64 design tasks cover compiler, planning, verification-as-task,
research stages, paper workflows, Generalist and summary adapter. Their small
semantic projections and authored answers are useful for subsequent bindings,
but are **not** original capsule input/output schemas. They explicitly require
product binding before live execution. The table→calculate→report graph is
likewise a design case, not a claim that a three-node workflow was executed.
No availability is inferred from a source catalog: actual CC-unit dispatch needs
a frozen active/admitted snapshot, exact compatible release pins and resources.

Literal expected outputs are authored without importing production workers or
checks. JSON object order is ignored; scalar types and array order are exact.
Report text is graded against literal escaped text, not a production renderer.
This strict development content grade is shared by both arms and kept separate
from unimplemented binding conformance. Model-based research cases will need
carefully specified projections before their exact-answer scores are meaningful.

All cases are locally authored adaptations of installed capability contracts;
none is an upstream benchmark result. The skill/helper receives public tasks
only and has no oracle, expected-answer, CC or verifier imports. When executing
native agent comparisons, retain these files and ordinary tools as available
assistance; do not restrict the baseline to tool-free prompting.
