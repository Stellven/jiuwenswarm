## Recovery and fixes

The original backend exception was discarded. A later attempt captured a
nonzero helper exit with empty stdout; its exact historical process error is
unproven. Neither unknown was rewritten as failure or success. Operator-only,
append-only acknowledgements retain exact request/result/snapshot/evidence
hashes and authorize distinct new work after local containment checks.
Same-request replay still returns the original unknown; new unresolved claims
block again. The relay now has an exclusive lifetime lock, helper stage/exit/
bounded stderr diagnostics, and a protected probe that cannot invoke a model.
The qualified relay has an owned long-lived Windows-to-WSL parent.

The binding request completed in about 32 seconds while its original gateway
used a 30-second proxy window. The first Harbor observer failed with HTTP 502.
Same-ID reconciliation found the completed request; a GET-only collection
generation validated its original archive and passed grading without another
POST or model call. The first observer, record, ledger and guard remain retained.
These are two observations of one scientific request, not independent trials.

The final deployment includes a finite 660-second evaluation POST transport
window, unchanged worker budgets, streamed original evaluation ZIPs and same-ID
reconciliation for server errors. App and receiver images are updated together.
Ordinary runner credentials require native refresh for a future campaign.
Independent admission calibration remains NOT_RUN; no formal M1 acceptance is
claimed.
