# Unified metadata dictionary (first increment)

Generated by `tools/so_docs.py`. Do not edit by hand. The machine-readable form is `unified-dictionary.yaml`.

One list of every metadata name a model in the factory can meet, from both sides:

| Side | Names | Source | Who maintains it |
|---|---|---|---|
| Engine | 310 | `ontology/dictionary.yaml`: file kinds, field names and fixed values of the System Ontology format | System Ontology workstream |
| Factory | 1144 | `docs/architecture/design-package/reference/`: the CC declaration, the other IR schemas, the shared field contracts | The factory's maintainers |

46 names are on both sides. This increment only reads the factory's files; it changes nothing in them.
A factory name has a meaning here only where the factory's own files give one.
