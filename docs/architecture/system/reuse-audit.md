## Probes the table implies

Each row's limitation is a source-supported adapter limit, not a tested behavior. Tests to write: a `CcHalt` raised inside `parallel()`, `pipeline()` and `map_parallel()` branches must reach the launcher and stop the script (an `Exception` subclass must fail this test); `run_workflow` called without a backend must be refused by the launcher assertion; two Codex profiles and a cancelled CC turn beside a surviving native chat; injected backend exception, schema failure and forged cache proving zero duplicate effects and zero unauthorized [releases](lifecycle.md#term-release); process-interruption recovery separated from host power-loss claims; a cache-only KV adapter that normalizes wrappers; CodeSearch import closure, worker limits and deterministic ties. [Planner](planner.md) is the home of proposal and validation; do not enable unrestricted native team tools as a shortcut.

Keep upstream types and behaviors inside [adapters](integration.md#term-adapter) (anti-corruption layer) so inherited cache, retry or team behavior never acquires CC authority. Adapters stay inside the Dockerized modular monolith. When a source pin changes, recheck [integration](integration.md) and [modules](modules.md).
