## Complete Intention Compiler: current bounded build

The [current build entrypoint](core-build.md) is the bounded core journey including the D19 planner. The [existing Intention Compiler entrypoint](builds/intention-compiler/README.md) is a reusable first component and historical calibration boundary; it covers qualified local intake → verified Intent IR → verified Brief → protected release plus its supporting foundations, not the complete core journey. Past compiler trial/TASK/interface identities remain historical and unchanged.

The existing compiler component proves its boundary only when a real supported request reaches accepted Brief with required evidence. Halt scenarios need separate failure evidence. It contributes reusable foundations and compilation, but does not implement the protected planner or scientific path and does not satisfy the current core assignment by itself. A bounded test consumer checks Brief compatibility without implementing research stages. Existing task/interface identities are reconciled under native coding records, not renamed by this design.
