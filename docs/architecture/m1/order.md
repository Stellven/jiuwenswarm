# Contract-first design order

The frozen October 2 PRD supplies the whitelist. [Pipeline](pipeline.md) owns the adopted capsule inventory and wiring; archived alternatives do not define coding tasks.

Design shared runtime/store/Gate contracts first, then requirement, search, screening, hypothesis, POC, scientific benchmark, evaluation and report/publication. For each boundary define owning input/output schemas, references, effects, errors, writer, Gate criteria and verification hooks before internal behavior. Implementers choose internal algorithms consistent with those outcomes.

Screening's mandatory offline RSI target is the local pure rank_opportunities helper, as stated by PRD 4.4. Text-level SKILL/rubric mutation is conditional on a bounded headless model path. Candidate mutation cannot alter live ranking code, Gate policy, dataset or thresholds; activation is separate and explicit.

The prior deterministic compile_intent capsule becomes ordinary optional launcher hints. The production compiler uses the PRD's one bounded semantic pass to emit the Research Brief. Isolated Phase 2 intention compilation and planning are separate orchestration services.

Use [module map](../system/modules.md), [coverage](../prd/coverage.md) and canonical [types](../types/types.md) as the coder's reading path. The architecture defines contracts; Spec Kit and executed system tests follow later.
