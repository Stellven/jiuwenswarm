# Architecture principles

`Tier 2 · Part of: [Method](README.md)`

These principles define what good and bad look like. A reviewer can judge a change without reading each case. A coder agent that is unsure applies the last column. The [decisions](decisions.md) give the reasons. The PRD owns product obligations. Where this page and a tier 3 contract differ on a field or a check, the contract wins.

| Principle | Good (success looks like) | Bad (failure looks like) | What to do when unsure |
|---|---|---|---|
| Accuracy over speed | Every output passes its checks before any successor reads it. A bad output stops that node ([D4](decisions.md#decisions-and-source-amendments)) | Garbage passes forward because it looks plausible. A check is relaxed to save time. A retry or repair hides a failure | Stop that node and record the reason. Never pass a doubtful output on |
| Checks belong to someone else | Protected code outside every CC runs the checks and gates. A CC only produces output ([D42](decisions.md#d42)) | A CC weakens, skips, reorders or edits a check. A producer calls its own output ready | Run the pinned check as written. If it cannot run, treat the output as failed |
| Declare first | Every effect, input, output, model need and limit is declared before use. Missing input stops the node with a named reason | An undeclared network, file or model effect. An invented default. A guessed field value | Stop with the reason. Report the gap to the declaration owner. Never invent a value |
| Unattended runs | The Intention Compiler makes intent clear at intake: an accepted Brief or a halt. After that the run follows its frozen plan and keeps rolling. Slight uncertainty is settled by declared defaults and recorded ([D50](decisions.md#d50)) | A run pauses for a person. A run replans mid-run. A value is picked silently | Use the declared default and record it. With no default, fail that node and write an escalation record |
| Failure isolation | A failed node stops itself and its dependents, which become `skipped`. Independent branches continue. Protected run-level stops halt the run ([D49](decisions.md#d49)) | A node failure aborts unrelated work. A dependent runs on failed input. A failed node is retried | Contain node failures locally. Halt the run if platform security or durable release cannot be enforced |
| Reproducibility | Exact versions are pinned. Every artifact, decision and record is saved, so anyone can replay and debug a run | Floating versions. An unsaved intermediate. Evidence overwritten | Pin more and save more, never less |
| Side systems never block | The router, the RSI workbench and the sidecar stay off the hot path. A run works when they are absent, off or broken. The Codex route is the default | Startup, import, test or release depends on a side system | Put the seam behind a port that defaults to off |
| One fact, one home; one name per concept | Each fact lives in one page and other pages link to it. Terms come from the [glossary](../glossary.md) | A copied rule that later drifts. Two names for one thing | Link to the home page and use the glossary term. If neither exists, report it |
| A measured negative result is valid | A correctly measured negative or inconclusive result is delivered like any other ([D29](decisions.md#d29)) | Criteria tuned or runs repeated until the result turns positive. A run halted because the science said no | Judge the process (matched, measured, recorded), not the sign of the result |
