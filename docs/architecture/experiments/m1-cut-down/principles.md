# Architecture principles

Research must be accurate, reproducible and evidence-backed. Block material misunderstanding or missing mandatory resources early; optional omissions can remain explicit. Deliver valid negative findings. Never pass merely to produce something plausible.

CCs produce work or assessments; protected infrastructure owns permission, checking assignments, persistence and advancement. A CC is neither a node nor a Node Execution Contract. Verifiers inspect submitted artifacts and evidence, not replacement answers. Every work invocation is captured and checked; node release also covers aggregate evidence. Guard outputs terminate with mechanical validation, not recursive review.

Deterministic checks precede semantic review. Mandatory failure, unknown evidence or persistence failure blocks release. Only committed accepted references reach successors. Observe effects before they occur; retrospective checking cannot undo disclosure.

Freeze graph, admitted pins, profiles, effective limits and contracts. Per-CC permissions intersect admission, node and policy; never pool authority. No silent retry, repair, replay, model switch or live graph rewrite. Human corrections create linked new work.

Intent records user meaning; Requirements produces the Research Brief governing work. Hypothesis fixes experiment-specific criteria before code/results. Use the authoritative fields/schemas and readable derived views. Model calls use protected routing/bridge; RSI uses isolated profiles/referees, inactive candidates and human activation.
