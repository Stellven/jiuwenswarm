# Shared client and platform benchmarking boundary

UI/CLI/TUI and optional sidecar/benchmarker use one authenticated versioned control plane. Readiness returns target/build, contract version, operations and distinct liveness/storage/auth/model/isolation states. Wrong target/version/capability blocks before submit. Private network clients use service DNS/container port and scoped token; browser uses host loopback. Clients have no release-state/fixture mounts or policy/activation privileges.

Submit original objective/resources, approved profile/mode/request identity and supported seed; return one run identity. Ambiguous transport completion requires reconciliation before retry, not duplicate research execution. Observe/reconnect never cancels or replays. Retrieve allowed named artifacts/Run Bundle; explicit cancellation stops dispatch/contains work and preserves effects. Stable structured terminal reason/exit supports headless clients without prompts. [Fields](reference/other-contracts.md#client-and-model-boundaries) standardize operations; implementation chooses routes/encoding.

Freeze campaigns/task sets/expected outcomes/configuration/pins before measurement. Match inputs, repetitions, seeds where supported; retain failed cases, unavailable usage and provider nondeterminism. Scientific metrics differ from platform pass/latency measures. Mocks are labeled; ablations disabling mandatory controls are invalid for product/admission. Evidence exports have audience/redaction identity and may feed only approved RSI development material. Optional sidecar internals remain separately scoped.
