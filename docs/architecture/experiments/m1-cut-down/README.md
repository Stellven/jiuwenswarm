# AI4Research M1: cut-down design input

**Experimental snapshot, full M1 scope.** The [PRD](sources/product/prd-m1-current-2026-10-07.txt) defines product acceptance. This design defines how to realize it. It is a compressed input, not the maintained architecture or a reduced milestone.

Other topic files are short connection summaries. Existing fragment links resolve into their condensed topic. They do not retain the omitted original explanation.

The application bundles frontend, web/control service and runtime; its entrypoint serves browser access through host-loopback port 5173. Governed work produces candidates, verification assesses them, protected code durably accepts or halts. Research proceeds from qualified request to Brief, evidence-grounded opportunity, registered protocol, bounded POC, matched measurements and a justified report. RSI is separate from the live DAG.

Contract/reference files, PRD and source decisions are unchanged from the full input. Both inputs cover all M1 phases. This package does not claim implementation, human approval or experimental success.
