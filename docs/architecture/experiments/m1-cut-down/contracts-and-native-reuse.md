# Native reuse and compatibility

Use existing JiuwenSwarm SwarmFlow, local Leader/Team, CC/provider catalogue, Codex bridge, run-tree, memory and native clients where they preserve declared boundaries. Validate actual dependency pins before choosing adapters; source inspection is a reuse lead, not runtime compatibility evidence. Swallowed faults, hidden retry, cache/replay or producer-owned acceptance are incompatible.

Symphony catalogue/provider seams can supply read-only eligible declarations for bounded binding. No live installation or permission growth. Concrete files/classes/transports remain native specification choices; [current field contracts](reference/other-contracts.md) and [CC declaration](capsule/declaration.md) own shared meaning. Native system maps/scorecards are projections; protected durable state remains acceptance authority.
