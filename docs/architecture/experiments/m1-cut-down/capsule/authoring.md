# CC authoring intent

Author the canonical [declaration](declaration.md) and pinned implementation against its typed ports, scope, permissions, dependencies, limits, pre/postconditions, evidence and tests. Human representation derives from declaration. Work produces payload; verifier produces assessment. Neither authors workflow release or trusted envelope metadata. Runtime contracts may narrow admitted authority, never broaden it.

Use required schema/field definitions, descriptive artifacts and source attribution. No independent provider client, hidden repair, effect expansion or policy mutation. Fixed mandatory output checking is independently assigned before execution; producer self-tests cannot waive it. Composite members require pinned closure, member observation and protected aggregate checking. Mutation targets exclude referee/contract/security. Changed implementation enters independent admission as a new version.
