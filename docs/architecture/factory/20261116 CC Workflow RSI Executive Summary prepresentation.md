# 20261116 CC Workflow RSI Executive Summary prepresentation

**November 16, 2026.** We extended the current M1-derived inference-engine factory, preserving its useful execution, evidence and governance features while continuing with CCv2 and dynamic workflows. The obsolete POC was not restored.

- **Integrated architecture:** CCs are functional packages; reusable nested subworkflows connect their capabilities; dynamic workflows compose procedures and record evidence-backed revisions. RSI uses historical results to choose source changes. One native host and Lab Manager retain execution and resource authority.
- **Unified interconnect:** implemented shared catalog schema 0.2.0 and the compatible factory.interconnect/1 binding profile. Connections carry named ports, collected result channels, bounded JSON projection/assembly and provenance. The downloaded catalog's 150 entries and 55 composition references round-trip without loss.
- **Real execution:** two STRATA source/build/screen cycles ran through the connected factory. The screens measured +8.30% and +9.28% decode throughput; the latter was 14.473 to 15.817 tokens/s. Exact outputs were preserved on three frozen prompts with unchanged model assets and quantization. Both missed the 10% gate, so neither received independent confirmation or serving promotion. These remain useful engineering results, not discarded failures.
- **Reusable research assets:** both candidate commits, named cloud branches, patches, build/image identities, measurements and limitations are retained. The library now has explicit searchable reusable-candidate records. A fresh-reader test and checks against the real records verify that another session can recover the code and evidence, then optionally build on them under a new task.
- **Reliability:** repaired retained-report discovery, authorized resume after terminal decisions, and native methodology gate/budget translation. Post-integration verification passed 111 tests and 3 subtests, including persistence across a fresh library reader. The service is healthy and the GPU and owned build containers are cleaned up.

**Cloud handoff:** [factory integration](https://github.com/Stellven/jiuwenswarm/tree/integration/native-cc-workflows), [idle-policy candidate](https://github.com/Muxite/Strata/tree/factory/review-20261116-arm64-idle), [combined candidate](https://github.com/Muxite/Strata/tree/factory/review-20261116-arm64-yield).
