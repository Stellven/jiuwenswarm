Architecture fixes responsibilities, approximate payload meaning, authority, trust/lifecycle boundaries, naming and compatibility. The owning TASK supplies versioned IF agreements; native spec/plan/tasks supply acceptance criteria, detailed realization, work and evidence. The M1 register references this current PRD and architecture. Coding agents finalize affected task details before dependent implementation. Preserve source clauses and unresolved decisions rather than inventing requirements or claiming runtime acceptance.

TRIAL-1 ends at checked intermediate intent. Later tasks cover the complete Brief, research journey, operational shell, independent offline RSI and applicable Phase 3 efforts. Register interface owners and dependencies before implementation; integrated M1 evidence belongs to its system task. No native artifacts or runtime evidence are claimed by this design.
