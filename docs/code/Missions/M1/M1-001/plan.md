### Research decisions and alternatives

decision: Extend SubscriptionService with invoke_governed using fresh per-invocation thread/context and same managed authentication, distinct from stream's chat binding reuse.; rationale: Actual existing transport owns pinned child/profile lock/stdIO/login and currently disables tools; ordinary chat session semantics cannot stand in for governed runs.; alternatives: Reject replacement model/auth facade, IDE-home reuse, raw direct API fallback and route via interactive chat.

decision: Versioned bounded length-prefixed JSON over Unix sockets with peer UID verification and session capability; validate body against canonical schemas before dispatch.; rationale: Use protected internal transport policy ipc_v1 with MAX_IPC_FRAME_BYTES=4*1024*1024, reusing the existing AppServerTransport 4 MiB stream bound as the implementation ceiling. Test exact cap and cap+1 frames. This is not a new operator-config field or product acceptance threshold.; alternatives: No HTTP model listener, broad host home mounts or caller-authored contracts.

decision: Append route and call-start using injected M1-IF-003@r1 durable writer before request submission; final failure may remain outcome_unknown and invalidates replay eligibility.; rationale: Existing transport closes on delivery-unknown and service epochs invalidate stale sessions; research extends these actual semantics.; alternatives: No retry-on-disconnect, secondary model switch or success inferred from process liveness.

decision: POC unshares network; Builder keeps approved model transport egress while Codex native workspace-write sandbox denies tool commands' networking.; rationale: Unsharing the whole Builder network would break actual model calls. D45 requires tool confinement, separate OS identity and credential, not a fictitious offline live CLI.; alternatives: Prompt/import scan alone insufficient; no blanket privileged app or Docker socket. If kernel/sandbox/cgroup custody unavailable, block executor readiness.

decision: Use dedicated immutable accounts volume distinct from run/workspace state and ephemeral per-call Builder credential path; use minimal trusted UID/cgroup launch helper with typed manifests and fixed executable allowlist.; rationale: Workspace deletion cannot revoke account/history retention or expose main secrets. Only protected launcher may change identity/cgroups; executor has no launch control privilege.; alternatives: No raw caller shell command, generic root helper API or shared main credential.

decision: Separate the closed operator configuration from account/host/project preferences.; rationale: M1-001 research/operator_config.py validates exactly operator-config1.0.0. M1-006 research/configuration.py resolves preferences against that approved operator model; preference values do not add fields to the closed operator schema.; alternatives: Do not reuse one mutable configuration file or widen the canonical operator schema to hold account preferences.

decision: Enforce the M1 native-channel allowlist before creating gateway clients and use owned tmux sessions for background services.; rationale: PRD5.5.1 requires managed background sessions/panes and inspection; PRD5.5.2 disables external chat.
