## Requirements

### Functional Requirements

- **FR-001**: Maintain a stable protected local product-user identifier and minimal durable trial defaults independently of individual run/workspace storage; bind every trial operation and persisted run to the authenticated user, authorized workspace and run identity. This is attributable local baseline support, not completion of account registration or broader profile management. Current authority: immediate-plan.md:L53-L67, immediate-plan.md:L68-L86.
- **FR-002**: Authenticate the trial local control plane with protected random session credentials and scoped host-derived authority, keeping browser and sequential headless access on the same application boundary. Current authority: immediate-plan.md:L53-L67, immediate-plan.md:L68-L86, immediate-plan.md:L87-L92.
- **FR-004**: Resolve only supported trial configuration into an immutable effective profile before work, with explicit precedence and protected compiler/verifier role, check and implementation identities. Current authority: immediate-plan.md:L68-L86, immediate-plan.md:L53-L67, immediate-plan.md:L87-L92.
- **FR-005**: Provide finite measurable compiler/verifier time and call budgets, and truthful requested/effective seed and usage metadata; consume actual enforcement/observations from the owned runner rather than claiming configuration alone enforces them. Current authority: immediate-plan.md:L68-L86, immediate-plan.md:L15-L52, immediate-plan.md:L87-L92.
- **FR-006**: Keep one active authorized local execution context and one sequential trial run, with the two static baseline Codex model roles; reject unsupported experimental routing and full-M1 mechanisms instead of implementing them. Current authority: immediate-plan.md:L68-L86, immediate-plan.md:L87-L92, immediate-plan.md:L93-L107.
