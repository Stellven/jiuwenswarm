### Data model, storage and recovery

**roots**: /var/lib/ai4r/router/audit.sqlite plus immutable decisions/events/catalog/profile snapshot refs; router read-only contract data and captured approved export paths. Only router-owned audit directory writable.

**tables**: route_claims keyed authenticated execution_id with immutable request fingerprint/state/deadline; route_events append-only by decision/execution; exact decision refs keyed content hash. Mutable lifecycle index never rewrites captured request/decision bytes.

**permissions**: Catalog/profile/capsule closures supplied as protected read-only data; provider credentials excluded from env/file grants. Socket and peer UID allowlists exclude CC/executor identities. Existing run/state database is never writable by router.

**recovery**: Same request returns stored outcome; changed request conflicts; owner loss with uncertain dispatch preserves unknown and cannot replay. Router audit loss returns AUDIT_UNAVAILABLE; core audit loss separately stops invocation.
