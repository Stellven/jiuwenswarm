# M1 reliability and ML readiness campaign

## Goal and limits

Improve M1 before the next benchmark session through small live tests, defect reproduction and bounded fixes. Use PRD V10 stories to prioritize grounded summaries, runnable POCs, measured conclusions, understandable halts and reproducible evidence.

- Use Luna agents for implementation, case generation and independent checks; the supervising agent reviews changes and verifies retained results.
- Default application model calls to `gpt-6-luna`; use separately frozen `gpt-6.1-sol` runs for difficult cases and reviewer comparisons. Preserve observed model identity. No model router or silent fallback.
- Stop live testing at **900 governed completion attempts or three hours from the first live call**, whichever comes first. Count failed attempts and repairs. This is a ceiling, not a spending target.
- ML is the primary scientific demonstration. π is optional.
- Leave official benchmark selection and statistical significance to the benchmark owner.
