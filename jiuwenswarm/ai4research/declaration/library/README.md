These two packaged files are trusted host seed templates. Their null source hashes are an explicit unseeded state, and fail normal declaration validation. `CapsuleLibrary.seed_builtin()` captures the referenced local bytes into a new, immutable, fully hashed inactive declaration. It never admits or activates a definition and never substitutes changed bytes under an existing identity.

The canonical admitted declaration and immutable source snapshots live in the protected SQLite library, with append-only admission and authenticated human standing histories. `make_capsule_markdown()` generates a human-readable view from that exact declaration. Client and model APIs must not expose admission, seeding or standing administration.

Only `intent_compiler` and `intent_verifier` are executable roles. Exactly two authored CCs exist; deterministic validation and final gate release are protected infrastructure. A fixture-only admission must be resolved with its scope explicitly and cannot run as real model-backed work.

Known compatibility metadata retains its meaning without granting authority; remote forms, overlays, internal composition and authored predicate execution are not executable in this trial. Quality metadata is not measured certification; author-controlled generalist exemption is forbidden. Lineage records authored versions; evolution notes/frozen promises are not an RSI permission system.

Model routing, actual runtime readiness and mandatory fidelity/profile assignment are protected host records. Native/runtime dependency identity and protected evidence receipt custody are validated by their owning readiness/store boundaries before host admission. The declarations provide a 300-second maximum per pass, zero tools and one pass. Frozen runtime configuration may narrow time limits; the library does not claim provider token, cost or seed control.
