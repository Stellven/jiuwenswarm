# Throughput improvement workflow

1. query/read retained reports and inspect the setting-specific engagement and risks.
2. apply one explicit setting and verify_profile against the original baseline;
   retain both profiles and the change. These calls do not submit jobs.
3. design reads a selected operator-installed template with its exact hash. Check
   that the intended profile treatment and frozen workload match. Publish a
   report-backed hypothesis and uncertainty; methods help choose a useful scope.
4. loop_status recovers revision and pending cycles. select reserves one exact
   admitted template and hypothesis. execute submits it once under GPU grants.
   END THE AGENT TURN after durable submission; the supervisor must stop control
   before quiet measurement. Do not poll or sleep in the model turn.
5. On resume, collect the original cycle, query/read its evidence and retain null,
   failed and unengaged outcomes. Choose independent confirmation only from a
   surviving screen. Do not multiply separate gains or promote defaults.
6. stop persists future admission stop intent; it does not cancel active jobs.
   Respect experiment budgets and the operator hard deadline.

This package composes shared runtime facilities. No mandatory traversal through
another capsule is required. Composition with another job package is appropriate
when it adds a distinct useful capability. Qualification from another package
never automatically qualifies these settings or broad runtime results.
