name: strata-budget-workbench
description: Design and verify one-variable Strata expert-residency experiments on a qualified fixed-budget engine.
---

Use this package when reducing resident expert memory while preserving full-six routing. Read METHOD.md and EXAMPLES.json. Call apply on the admitted profile; retain the original as control. This constructs a candidate, not permission to execute it. Submit through an admitted lab runner or operator-frozen experiment. Call verify_startup on each fresh process, then summarize_memory on its durable samples. Compare both prefill and decode, exact generated tokens, and sampled quality. Attach all observations to the current branch; keep memory scopes separate. A successful profile transform does not establish feasibility or quality.

Do not call this for precision changes, expert dropping, dynamic caches or automatic placement. Another CC can help interpret the resulting evidence; it need not be interlaced with this package's core job.
