# Job: transfer a methodology and choose the next discriminating experiment

This package includes compatibility triage, a bounded trial designer, a reusable
timing-analysis component, actual measured example inputs and independent local
verification. It is usable without another research capsule. Other CCs supply
optional domain-specific implementations after an agent chooses a candidate.

For expert caching, test byte budgets, in-flight pins, trace causality and request
holdout first. For streaming, test exact reads and completion ordering on a small
owned file. For heterogeneous execution, compare measured operation costs and
count shared physical memory once. For kernels/precision, check reference
outputs and numerical budgets. For KV reuse, check full context identity and
copy-on-write. For serving, check queue capacity and starvation before throughput.

Do not combine all successful micro-tests into one engine patch. Change one
mechanism, verify engagement, then compare the workload it is intended to help.
The supplied 4096/16 and 128/512 recipes separate prompt-heavy and generation-heavy
work; sizes can be changed in an explicitly new admitted contract. Neither is an
official llama.cpp score or a semantic benchmark. Two ABBA pairs yield descriptive
ratios, not strong confidence. Identical sampled answers do not establish equal
generated trajectories or full-model semantic equivalence.

RSI can improve input ergonomics, rejection quality, execution cost and useful
decisions against fixed examples. Keep the original examples and checker outcomes
as holdouts; do not optimize merely to emit the expected recommendation string.
