# Bounded positional streaming reference

`plan` and `evaluate` accept `inputs.ranges`: `[offset,length]` pairs, and optional `max_gap` bytes. Coalescing sorts ranges, merges overlap/adjacency and configured gaps only within a 16 MiB maximum read. Duplicate inputs are preserved by read reconstruction. `evaluate` additionally accepts `bytes_per_second`, `read_latency_seconds`, `max_inflight`; its greedy independent-lane cost model assumes each lane has the specified bandwidth. This can overestimate shared-SSD throughput and is explicitly a model, not a benchmark. No SSD topology, cache state or PCIe cost is inferred.

`read_fixture` accepts inline UTF-8 `data` (1 MiB maximum) and byte ranges. It writes only an owned TemporaryFile, performs real positional reads in a bounded two-worker pool, reconstructs input-order slices as hex, and closes all workers before closing the file. No caller-supplied paths or descriptor are exposed through CC tools.

`BoundedPread` in components.py is the explicit integration component. A caller owns the descriptor and must close the reader before closing it. Submission enforces both count and byte bounds with BlockingIOError backpressure. `cancel()` marks queued and running results unusable; an already running POSIX pread cannot be interrupted, and close waits. Short reads raise EOFError. Arbitrary descriptor integration must be authorized by the embedding runtime. Coalescing is a separate reusable planner. This uses portable CPU ThreadPoolExecutor and POSIX pread, not io_uring, GPUDirect or asynchronous GPU copies.

GB10 unified CPU/GPU memory differs from separate host-RAM/PCIe-VRAM systems described by LayerStoRm. SSD-to-memory data motion remains relevant; H2D overlap and multi-GPU bandwidth claims do not transfer automatically. 384 experts × 40 layers × 6 active is a workload geometry, not evidence that these bytes fit memory or achieve a rate. Measure actual sizes, memory headroom and target-storage behavior before deployment. Run `python verification.py` for CPU checks only; no factory cc_qualification admission is claimed.
