# Common-history numerical investigation

This CPU-only package freezes replay specifications, locates output differences and analyzes externally supplied logit vectors. It does not instrument Strata, run teacher forcing, capture logits, find a divergent layer, launch a GPU or authorize a lab experiment. A source-pinned adapter plans and imports the existing DS4_SERVE_DUMP hook for the initial output49 diagnostic. Actual capture execution and general forced replay remain unverified. Synthetic verification data is never engine evidence.

Start from the qualified local Strata baseline and the retained pg512/tg128 failure. Token index49 (the50th output token) differs after49 common tokens; the retained baseline/candidate IDs are10367/32187. Freeze prompt tokenization and the common teacher-forced prefix. A replay at step49 means prompt IDs plus teacher_ids[:49], immediately before choosing output index49. Never compare later free-running histories as evidence of the first cause.

Before capture, retain an immutable policy document and its declaration_id, numerical tolerances and top_k. The tool hashes the supplied policy; it cannot prove that an external declaration predates the capture. The caller/verifier must check the independently retained declaration timestamp and content. Never relax an existing frozen exactness contract after seeing speed or numerical results. New arithmetic studies require their own advance policy; tolerance success alone establishes neither engine qualification nor quality noninferiority.

Identity has exactly six immutable references: model (checkpoint/pack plus quantization), tokenizer (assets and configuration), source (engine/build/image closure), precision (arithmetic configuration), routing (expert selection configuration), profile (all launch arguments/environment). Use content-addressed retained manifests, never mutable aliases. These are caller-provided provenance references, not independent authentication. Model/tokenizer must always agree. Any source/precision/routing/profile differences must exactly equal treatment_fields; no undeclared differences or treatment fields that conceal equal identities. Profile references may differ only for the admitted treatment; independently inspect the profile manifests to ensure a one-variable treatment. This tool cannot infer manifest contents from a reference string.

replay_spec freezes prompt_ids, teacher_ids, step, vocabulary_size, arm identities and policy. Persist the spec and SHA256 before capture. Hold teacher forcing constant between arms. Source closure and replay sequence must also bind checkpoint/precision and routing. Preserve observer-disabled runs and capture-enabled runs for both arms; compare output tokens/finish and repeated timing separately before interpreting performance. Exact output agreement does not establish zero observer overhead.

A capture contains exactly identity, spec_sha256, history_ids, step, vocabulary_ids, logits, complete and capture_id. The history must equal the frozen prompt-plus-prefix exactly. vocabulary_ids are integer token IDs, unique and in [0,vocabulary_size); logits are matching finite numbers. A full capture must cover the entire vocabulary. Pair vector entries by token ID, never array offset. Bounds:32MiB serialized request,262144 vocabulary IDs,16384 history tokens,4096 teacher/output tokens, top_k1..32. Scalar identity/capture references are limited to256characters. Invalid input fails; it is never truncated.

For each token, compare abs(candidate-baseline) <= absolute_tolerance + relative_tolerance*abs(baseline). Tolerances must be finite in [0,1]. Retain maximum absolute difference, violation count and exact-vector identity separately. Full vectors yield top candidates, top1-minus-top2 margins, ties and same-top choice. Deterministic tie display sorts by ascending token ID; it is not a promise about an engine sampler's tie behavior. Subtractions that overflow fail safely. Partial vectors must cover identical token subsets in both arms; observed differences are retained, but full-vector exactness, tolerance, top choice and margins remain unknown. No probability or sampling equivalence is claimed.
