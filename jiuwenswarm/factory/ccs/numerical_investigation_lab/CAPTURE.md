# Native full-vector capture

This adapter uses the existing `DS4_SERVE_DUMP` path in `src/dsv41/ds4_main.cpp`, SHA256 `fb3ff96a416b8efe077c5eecffd1bdbdf957ebc36cd8ae7f8ff86e50a4aa3973`. The inspected checkout revision is `ffa80d73133ea5c548aefe57889a16e8085a938f`. This pins the native entry source file, not the whole engine or executable. Record the actual source/build revision and image/binary digest separately in frozen identities and retained build witnesses. No patch or compilation is needed to use the existing path.

`capture_plan(profile, spec, arm, dump_prefix)` validates the fixed six-expert/no-drafting/static-cache profile and freezes a single `GEN 50 temperature=0 top_p=1 top_k=1 min_p=0 seed=42 spec=0` request with the original prompt IDs. The spec's arm profile identity must equal SHA256 of the original canonical JSON profile (bare hex or `sha256:` prefix). Only the plan's observer environment adds `DS4_SERVE_DUMP`; it never launches a process. Baseline and candidate have separately frozen profile hashes. Model/tokenizer/source/precision/routing identity remains caller supplied and must have independent build/input witnesses.

The native source opens `<prefix>.1.f32` after prompt ingestion, writes its full last-row logits, then writes each no-draft decode row. Row0 selects output0; row49 selects output49 after outputs0..48. Native `fwrite` return values are unchecked, so import requires exactly50 rows times vocabulary size times4 bytes and rejects truncation. A fresh single-conversation process and one request are required. The importer rejects native errors, cancellation, early EOS, nonzero draft counts, wrong prompt length, incomplete outputs, nonfinite selected logits and any mismatch against teacher tokens0..48. This is common-history verification after ordinary generation; it does not force an externally chosen teacher prefix.

`import_capture(spec, arm, evidence_root, dump_path, transcript_path, stdin_path, profile, source_main_sha256)` reads only explicitly supplied relative files within the resolved evidence root, including symlink containment checks. It bounds raw data to256MiB and transcript to4MiB. Supply the native stdout transcript and exact sent stdin file: the frozen request line followed by `QUIT`, each newline terminated. Extra requests or changed prompt IDs fail. Use `--eos -1` in the separately frozen diagnostic profile to prevent early EOS; the adapter preserves that argument. The output contains the numerical package's exact full-vocabulary capture schema and separate hashes/provenance. Complete imported captures establish a checked input for numerical comparison, not authenticated origin or runtime parity.

When recorder mounts are read only and `/tmp` disappears at exit, use the explicit wrapper entry point:

```
python /mounted-package/capture_wrapper.py --vocabulary-size V -- /opt/strata/strata-dsv41 --serve --dspark none ...
```

The wrapper inherits stdin/stdout/stderr, creates a private `/tmp` FIFO at the first dump path, starts a nonblocking reader before launching the original engine, drains the stream into bounded RAM, waits for exit and exports one `STRATA_NUMERICAL_CAPTURE ` JSON line to stderr. Preserve the native stdout and wrapper JSON in owned evidence files, then call `import_capture` with the JSON as `dump_path`. Its `strata-native-logit-row/1` witness includes row49 as little-endian float32 base64, vocabulary size,50 rows, raw size/hash, selected-row hash and entry-source pin. The importer recomputes the selected-row hash; the full raw hash is a wrapper witness and explicitly marked `full_raw_hash_recomputed=false`. A raw dump import recomputes that hash itself. Do not relabel a wrapper witness as independently authenticated provenance.

The observer calls `m.logits` and may synchronize the device or change timing. Run a separately authorized observer-off/on comparison before claiming behavior preservation, and exclude these cells from speed scoring. No GPU or native engine execution is performed by the plan/import CC tools. CPU tests use generated float fixtures and a fake child process; they do not qualify the model or native runtime.

The importer accepts the direct exact GEN/QUIT wire or that same wire preceded by one recorder gate line: ASCII FACTORY_EXEC followed by byte10 (a physical newline). It rejects duplicate gates, extra requests and literal backslash-n forms. The gate is consumed before native stdin; original wire bytes remain hashed.

Wrapper rejection now emits a structured `STRATA_NUMERICAL_CAPTURE_ERROR` witness before cleanup, with actual and expected byte counts, complete rows, row/float alignment remainders, dump file count, bounded SHA256 and its hash scope, child exit code and file stability. A failed capture remains failed; these diagnostics do not infer vocabulary dimensions or permit partial vectors. A nonzero child exit also retains available dump diagnostics. The initial runtime probe lost its dump after dimensional rejection; its failure remains evidence and cannot establish full-vector equivalence.

The FIFO transport avoids allocating the full raw dump on the recorder's64MiB `/tmp` filesystem. It retains at most the expected byte count plus one byte, continues draining overflow so a writer cannot deadlock, and rejects any overflow, truncation, missing writer, failed engine or extra request file. A child exit triggers buffered draining then reader termination; the existing recorder still bounds child lifetime. `STRATA_NUMERICAL_CAPTURE_RESOURCES` reports `/tmp` free/total bytes before and after successful capture separately from the unchanged row-witness schema. Failure witnesses include free bytes too. Low measured free space supports a storage-pressure hypothesis; the earlier truncated dump alone does not establish its cause. CPU fake-engine tests cover complete capture, short dump, missing writer, excess writes, extra request and nonzero exit.
