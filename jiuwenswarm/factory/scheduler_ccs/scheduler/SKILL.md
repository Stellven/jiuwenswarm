---
name: factory-scheduler
description: Finalize one preliminary node contract just before the node runs - fill its slots from evidence, bind capsules, never weaken it.
---

Call brief with the node id first and read everything in it that bears on this node before you fill anything: task (the task record, the whole task contract and every node contract), plan and neighbours (where this node sits and what the next node needs), the node's briefing (the planner's facts, pitfalls and how to fill the slots), upstream (the admitted finals, accepted checks, cited evidence and capped runs of the done nodes), history (operator records, halts, refusals, and this node's earlier finals and failures), machine (state and job queue) and capsules (each capsule's cc.yaml, docs, verification units, files and how it did earlier in this run). When the brief cuts an item it says how to read it whole: capsule ({"id": ...} lists a capsule's files, {"id": ..., "path": ...} reads one) and evidence ({"id": ...} reads one record of this task). When a slot depends on how a capsule works or on what a run measured, read it instead of guessing. Then build the final contract from its draft_final: fill every slot with a value grounded in cited evidence, bind capsules in work.bound_ccs, keep every criterion word for word (you may keep or extend the briefing), and propose the whole contract with a rationale that names the evidence id behind each value. A refusal lists the reasons; fix them and propose again. If the preliminary contract cannot be met as written, do not propose a weaker one: report the spec gap. The full role is in the turn's instructions (SCHEDULER.md).
